# EcoFlow River 2 — заряд в трее

`EcoFlowTray.exe` показывает в трее Windows иконку с процентом заряда:
- зелёная — больше 50 %, оранжевая — 21–50 %, красная — порог и ниже (плюс всплывающее предупреждение), синяя — идёт зарядка, серая — нет данных или станция не в сети;
- подсказка при наведении: процент, входная и выходная мощность, оставшееся время;
- левый клик — обновить сейчас, двойной клик — настройки, правый клик — меню (настройки, запуск вместе с Windows, выход).

## Откуда берутся данные
У River 2 нет локального API в Wi‑Fi сети. Станция отправляет телеметрию в облако EcoFlow,
а приложение читает её через официальный **EcoFlow Open API**:
- **основной источник — MQTT** (`mqtt-e.ecoflow.com:8883`, топик `/open/<account>/<sn>/quota`): станция присылает изменения каждые 1–3 секунды;
- **запасной — HTTP** `quota/all`: это снимок из кеша облака, он может отставать на часы. Используется только при старте и когда MQTT молчит больше 2 минут. В подсказке тогда написано «(кеш облака)».

Левый клик по иконке показывает подробности и время последнего обновления.
Журнал работы: `%APPDATA%\EcoFlowTray\log.txt`.

## Настройка (один раз)
1. Зайдите на https://developer.ecoflow.com под тем же аккаунтом, что в мобильном приложении EcoFlow.
2. Нажмите «Become a Developer» и подайте заявку. Её обычно одобряют в течение нескольких дней, придёт письмо.
3. В разделе Security создайте пару **Access Key / Secret Key**.
4. Запустите `EcoFlowTray.exe`, вставьте ключи и нажмите «Найти»: серийный номер подставится сам.
   Сервер: `api-e` — Европа, `api-a` — Америка. Если появилась ошибка про сервер или ключи, попробуйте другой.

Настройки хранятся в `%APPDATA%\EcoFlowTray\config.json`. Secret Key сохраняется зашифрованным (Windows DPAPI).

## Сборка
`build.bat` — использует компилятор C# из .NET Framework 4, который уже есть в Windows 10/11.
