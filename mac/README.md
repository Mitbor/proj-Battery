# EcoFlow Tray для macOS — строка меню + виджет

- **Строка меню:** значок батареи и процент рядом с часами. По клику открывается окно: процент, входная и выходная мощность, оставшееся время, время обновления, настройки, запуск при входе.
- **Виджет** на рабочем столе или в Центре уведомлений, два размера: малый и средний.
- **Источник данных** тот же, что у Windows-версии. Основной — живой поток MQTT EcoFlow Open API, станция присылает данные каждые 1–3 секунды. Запасной — HTTP-снимок из кеша облака.
- **Модели:** River 2, Delta 2, Delta 3 Plus, Delta Pro 3. Обычную Delta 3 EcoFlow в Open API не пускает: будет ошибка 1006.

Требования: macOS 14 (Sonoma) или новее, Xcode 15+ (бесплатно из App Store), Apple ID.

## Сборка (один раз)

```bash
# 1. XcodeGen генерирует проект Xcode из project.yml
brew install xcodegen          # если нет Homebrew: https://brew.sh
cd proj-Battery/mac
xcodegen
open EcoFlowTray.xcodeproj
```

2. В `project.yml` замените `BUNDLE_PREFIX: com.mitbor` на свой уникальный префикс, например `com.ivanpetrov`, и снова выполните `xcodegen`. Apple не даёт двум людям использовать один и тот же идентификатор.
3. В Xcode выберите проект, затем **Signing & Capabilities**. Для **обеих** целей, `EcoFlowTray` и `EcoFlowWidget`, укажите **Team**: подойдёт и бесплатный «Personal Team» вашего Apple ID.
4. Выберите схему **EcoFlowTray** и нажмите **Run** (⌘R). В строке меню появится значок батареи.
5. Кликните по значку, затем **Settings…**, и введите Access Key и Secret Key с developer.ecoflow.com. Кнопка **Find** подставит серийный номер.
6. Добавьте виджет: правый клик по рабочему столу → **Edit Widgets…** → найдите **EcoFlow Battery**.

Чтобы пользоваться без Xcode: **Product → Archive → Distribute App → Copy App**, затем перенесите `EcoFlow Tray.app` в «Программы» и включите в меню **Launch at login**.

## Как обновляется виджет

Виджет показывает данные, которые ему передаёт приложение из строки меню, поэтому приложение должно быть запущено. macOS ограничивает частоту обновления виджетов. Приложение просит обновить виджет, когда меняется процент или состояние зарядки, но не чаще раза в минуту. Плюс раз в 15 минут виджет обновляется в любом случае. В строке меню данные всегда живые.

## Если что-то не работает

- **Виджет пишет «Open EcoFlow Tray and enter your keys»:** приложение не запущено или у целей разные Team. App Group (`<TEAMID>.ecoflowtray.shared`) работает, только если обе цели подписаны одной командой.
- **Ошибка «broker rejected the login (code 5)»:** EcoFlow ограничивает число разных MQTT client ID на аккаунт. Старые версии создавали новый ID при каждом подключении и могли исчерпать лимит. Теперь ID постоянный; блокировка снимается сама, обычно в течение суток.
- **Подробности по соединению** в журнале `~/Library/Logs/EcoFlowTray.log`. Там же есть строка `MQTT sample` со списком полей, которые прислала станция. Если у вашей модели не показывается мощность или время, пришлите эту строку.
